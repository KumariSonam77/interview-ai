# Interview AI 

An AI-powered interview preparation platform that helps candidates prepare for job interviews using their resumes and job descriptions.

##  Live Demo

**Live Website:** [ https://interview-ai-frontend-nine-rust.vercel.app/home ]

## Features

- User Registration and Login
- JWT Authentication
- Resume Upload
- Job Description Input
- AI-Powered Interview Preparation
- Interview Reports
- Responsive Dashboard

## Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- JavaScript
- REST APIs
- JWT Authentication
